# Gemini и Claude через Psiphon

[Руководство по установке и проверке](references/deploy-and-test.md) содержит команды для новой установки и обновления, примеры Xray, проверки и откат. Для Claude, Anthropic API и Claude Code открой также [проверки Anthropic](references/anthropic.md). Меняй маршрут того сервиса, который указан в запросе.

1. Найди действующий источник конфигурации Xray, список нод общего профиля и сетевой режим Xray на каждой ноде. Для существующего Psiphon проверь состояние, привязку и фактический выход. Переустановка нужна при обновлении или изменении параметров установки.
2. Сравни прямой и проксированный запросы. Перед изменением сохрани рабочие настройки и зависимости от текущего SOCKS. Сначала проверь туннель на одной ноде. В общем профиле используй адрес и порт, достижимые из Xray на каждой подключённой ноде.
3. Для Xray на хосте или в Docker host network выбери loopback. Для Docker bridge узнай gateway конкретной сети контейнера. Проверь соединение из сетевого пространства Xray и доступность SOCKS только для нужных клиентов.
4. Обнови существующий outbound и доменное правило без дублирования. Сохрани первый outbound и действующие ограничения доступа. Правило сервиса должно предшествовать общему правилу, которое иначе его перехватит. Проверь итоговый конфиг бинарником Xray ноды. В Remnawave изменение вносится в серверный профиль панели.
5. Проверь запрос модели через VPN-клиент и выбор нужного outbound. Обычный HTTPS-запрос должен сохранить прежний выход. Для отчёта достаточно обезличенных результатов, версии и способа отката. Исходные конфиги, токены, ссылки подписок, cookies и необработанные журналы храни в закрытых местах.

Доступность SOCKS, загрузка страницы Gemini и ответ модели проверяются отдельно. HTTP 200 страницы показывает доступность сайта. Результат встроенной проверки зависит от формата ответа Google. Для конкретного аккаунта нужна отдельная авторизованная проверка. При смене выхода проверь, изменился ли фактический IP. Если несколько попыток дают тот же отказ, вернись к диагностике.
