# Claude, Anthropic API и Claude Code

Используй этот раздел вместе с общим руководством Psiphon, когда текущий запрос касается Claude или Anthropic. Маршрут Gemini не доказывает пригодность того же выхода для Anthropic.

## Что можно установить сетевой проверкой

Разделяй четыре результата: соединение с сервером, прохождение Cloudflare, авторизацию и получение ответа модели. Доступ к одному уровню не подтверждает следующие.

У Anthropic есть [список поддерживаемых регионов](https://www.anthropic.com/legal/supported-regions) и [отдельная справка о доступности Claude](https://support.claude.com/en/articles/8461763-where-can-i-access-claude). Сверяй их при текущем развёртывании. Иностранный выходной IP не подтверждает соответствие аккаунта или пользователя этим условиям. Не обещай защиту от блокировки аккаунта, «антидетект» или уменьшение риска бана только за счёт Psiphon.

В [рекомендациях по ошибкам входа](https://support.claude.com/en/articles/12466728-troubleshoot-claude-error-messages) Anthropic предлагает проверять доступ без VPN. Поэтому сначала сравни прямой и проксированный пути, а не считай общий прокси заведомо лучшим выходом.

## Первичная проверка без ключа и cookies

Проверь один и тот же запрос с каждой нужной ноды напрямую и через выбранный SOCKS. Не записывай cookies, ключи или полные заголовки авторизации в отчёт.

```bash
curl -sS --noproxy '*' --connect-timeout 8 --max-time 25 -D /tmp/anthropic-direct.headers -o /tmp/anthropic-direct.body -w '%{http_code}\n' -H 'anthropic-version: 2023-06-01' https://api.anthropic.com/v1/models
curl -sS --noproxy '' --socks5-hostname 127.0.0.1:1080 --connect-timeout 8 --max-time 25 -D /tmp/anthropic-proxy.headers -o /tmp/anthropic-proxy.body -w '%{http_code}\n' -H 'anthropic-version: 2023-06-01' https://api.anthropic.com/v1/models
```

Адрес SOCKS замени фактическим. Сохраняй диагностические файлы с ограниченными правами и не загружай исходные тела/заголовки в публичное хранилище.

Как интерпретировать результат:

- JSON `401 authentication_error`, например `x-api-key header is required`, означает доступ до слоя проверки авторизации. Это ожидаемый результат запроса без ключа; он не доказывает успешную генерацию, отсутствие ограничений аккаунта или пригодность выхода при авторизованном запросе.
- HTML `403` с `cf-mitigated: challenge`, страницей `Just a moment` или ресурсами проверки Cloudflare означает challenge. Это не равнозначно региональной блокировке и не является основанием бесконечно менять IP.
- JSON `403` анализируй по типу и тексту ошибки. Ограничение региона, права организации и отказ ключу — разные причины.
- `429` может означать ограничения запросов или квоты; смена страны не является исправлением по умолчанию. Ошибки `5xx` сверяй с [состоянием сервисов](https://status.claude.com/).

Веб-проверка:

```bash
curl -sS --connect-timeout 8 --max-time 25 -D /tmp/claude.headers -o /tmp/claude.body -w '%{http_code}\n' https://claude.ai/login
```

Повтори её через SOCKS. Если оба пути показывают Cloudflare challenge, curl не подтвердил пригодность ни одного пути для веб-клиента. Для проверки входа используй обычный браузер и доступную в рамках задачи сессию пользователя, не запрашивая пароль или cookies в чат. Не пытайся обходить challenge подменой результатов проверки.

Если задача требует полного теста API, используй предоставленный для этой задачи секрет штатным способом. Успешный `GET /v1/models` с подходящим ключом подтверждает авторизацию и доступ к этому endpoint, но не генерацию. Тестовый вызов модели выполняй в рамках разрешённого использования и бюджета; не собирай чужие ключи из соседних проектов.

## Отдельное правило Xray

Включай правило для Claude, когда оно запрошено и выбранный выход проверен. Если пользователь только обсуждает целесообразность и улучшения не обнаружено, сохрани рабочий путь и сообщи результат сравнения.

Пример с уже существующим, проверенным для Anthropic outbound `psiphon-out`:

```json
{
  "type": "field",
  "ruleTag": "ANTHROPIC_PSIPHON",
  "network": "tcp",
  "domain": [
    "domain:anthropic.com",
    "domain:claude.ai",
    "domain:claude.com",
    "domain:claudeusercontent.com"
  ],
  "outboundTag": "psiphon-out"
}
```

Это основной явный список, а не гарантия охвата любого продукта. `domain:anthropic.com` включает `api.anthropic.com`, а `domain:claude.com` — консоль и другие поддомены. Проверь актуальные официальные требования запрошенного клиента; добавляй недостающие домены по наблюдаемой необходимости. Альтернатива — `geosite:anthropic`, если такая группа есть в установленных геоданных и её фактический состав соответствует задаче. Сторонний список доменов не является официальной гарантией принадлежности всех записей Anthropic.

Правило должно быть независимо от `GEMINI_PSIPHON`: его можно проверить и отменить отдельно. Держи связанные запросы авторизации, API и контента одного клиента на согласованном пути. Не переключай весь Cloudflare, Google Login или общие CDN только из-за одного challenge.

Общий Psiphon-выход допустим, если он проверен для обоих сервисов. Но штатный watchdog установщика ориентирован на Gemini: его результат не является проверкой Claude, а его ротация меняет IP также у всех остальных потребителей этого выхода. Если нужна независимая политика восстановления, используй отдельный экземпляр Psiphon с другим локальным портом и outbound, затем проверь его отдельно. Не создавай второй экземпляр без необходимости текущей задачи.

## Особенность Claude Code

По [официальной документации сети Claude Code](https://code.claude.com/docs/en/network-config) клиент поддерживает HTTP/HTTPS proxy, но не прямую настройку SOCKS proxy. Не предлагай `HTTPS_PROXY=socks5://...` как рабочую настройку Claude Code.

При маршрутизации на стороне Xray приложение использует обычное VPN-подключение; поддержка SOCKS самим Claude Code для этого не нужна. Если нужен отдельный прокси приложения, используй проверенный HTTP CONNECT-вариант и предусмотренные клиентом параметры, сохраняя проверку TLS. Не публикуй HTTP-прокси на публичном интерфейсе и не меняй глобальную среду других приложений.

## Что записать в результат

Укажи проверенные узлы, прямой и проксированный результаты, тип отказа, включён ли маршрут, какие клиентские профили проверены. Отдельно обозначь уровень доказательства: сеть/API-auth endpoint, авторизованный API, вход в веб-клиент или ответ модели. Отсутствие ключа/сессии ограничивает проверку; его нельзя выдавать за подтверждение работы аккаунта или безопасности от блокировки.

Не добавляй ротацию по любому коду ошибки Anthropic. Перед сменой выхода отличи отказ именно сети/IP от challenge, истёкшей сессии, квоты, ошибки ключа и ограничений аккаунта. Сохрани результат Gemini после изменения общего выхода. Откат выполняй через владеющий профиль, удаляя только добавленное правило Anthropic и не затрагивая работающий маршрут Gemini.
